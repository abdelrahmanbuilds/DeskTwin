# DeskTwin bundled fonts

These font files are bundled locally so the app does not need a network connection to render its themes.
Each font is distributed under the SIL Open Font License (OFL); the matching full license text is kept
beside this file.

| Theme | Latin family | Arabic family | Bundled file names |
|---|---|---|---|
| DeskTwin Blue | Manrope | Noto Sans Arabic | `desktwin_manrope.ttf`, `arabic_noto_sans.ttf` |
| Cosmic Glass | Space Grotesk | Noto Kufi Arabic | `cosmic_space_grotesk.ttf`, `arabic_noto_kufi.ttf` |
| Codex Studio | JetBrains Mono | Noto Sans Arabic | `codex_jetbrains_mono.ttf`, `arabic_noto_sans.ttf` |
| Claude Ember | Lora | Noto Naskh Arabic | `ember_lora.ttf`, `arabic_noto_naskh.ttf` |
| Orchard Minimal | Nunito | Noto Kufi Arabic | `orchard_nunito.ttf`, `arabic_noto_kufi.ttf` |

The original Google Fonts family sources are in the official `google/fonts` repository:

- [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope)
- [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk)
- [JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono)
- [Lora](https://github.com/google/fonts/tree/main/ofl/lora)
- [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito)
- [Noto Sans Arabic](https://github.com/google/fonts/tree/main/ofl/notosansarabic)
- [Noto Naskh Arabic](https://github.com/google/fonts/tree/main/ofl/notonaskharabic)
- [Noto Kufi Arabic](https://github.com/google/fonts/tree/main/ofl/notokufiarabic)

The license text files in this folder are preserved with the app's bundled font assets.
