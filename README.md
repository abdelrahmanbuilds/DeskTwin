# DeskTwin

DeskTwin connects an Android phone to a Windows PC over the local network. Browse and transfer files within folders you explicitly share, pair devices with a QR code and TLS certificate pinning, and use the desktop and mobile companion features.

## Get started

1. Download the latest Windows package from [GitHub Releases](https://github.com/abdelrahmanbuilds/DeskTwin/releases). Install Python 3.11 or later and the .NET 8 Desktop Runtime, then follow the setup in Windows/README.md.
2. Install the Android APK from the same release on Android 8.0 (API 26) or later.
3. Connect both devices to the same trusted local network. Start DeskTwin on Windows, create a pairing QR code, and scan it in the Android app.
4. Select only the Windows folders you want to share. The phone can browse files in those folders; it does not receive unrestricted access to the PC.

The Windows computer hosts the local service. DeskTwin does not require a cloud account. Network discovery and pairing can be affected by Wi-Fi client isolation, VPNs, and firewall rules. See docs/SECURITY.md for the security model and docs/DEVELOPMENT.md to build from source.

## Build status and releases

Pushes and pull requests build the Android debug variant and Windows app. Creating a v-prefixed tag publishes a testing preview with a Windows package and an Android debug APK. This is a hands-on testing build, not a Google Play release.

The Android debug APK is signed with a temporary debug key generated by the GitHub Actions runner. Installing a later preview may require uninstalling the previous preview first, which removes its local app data. See docs/RELEASING.md.

## Project status

This repository documents and builds the current source tree. Preview artifacts are generated by GitHub Actions; APKs and Windows packages are not committed to the source tree. Hardware/device behavior still depends on the Windows network, firewall, Android version, and device-specific media support.
